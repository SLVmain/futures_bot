# Запуск бота на ноутбуке

## Важно

- Не запускайте одновременно службу и `python telegram_bot.py`.
- Пока служба работает, ноутбук должен быть подключён к питанию и
  интернету.
- Закрытый работающий ноутбук нельзя оставлять в сумке или другом
  месте без вентиляции.
- Блокировать экран и закрывать крышку можно только после проверки,
  что служба имеет статус `active (running)`.

## Первый запуск и включение автозапуска

```bash
systemctl --user enable --now futures-bot
```

Проверить состояние:

```bash
systemctl --user status futures-bot
```

В рабочем состоянии должна быть строка:

```text
Active: active (running)
```

Проверить бота в Telegram:

```text
/ping
/mode
```

При последующих запусках, если автозапуск уже включён:

```bash
systemctl --user start futures-bot
```

## Просмотр журнала

Показать последние сообщения:

```bash
journalctl --user -u futures-bot -n 100 --no-pager
```

Следить за журналом в реальном времени:

```bash
journalctl --user -u futures-bot -f
```

Для выхода из просмотра нажать `Ctrl+C`. Это останавливает только
просмотр журнала, а не бота.

## Перезапуск

```bash
systemctl --user restart futures-bot
```

После перезапуска снова проверить:

```bash
systemctl --user status futures-bot
```

## Остановка

```bash
systemctl --user stop futures-bot
```

Проверить:

```bash
systemctl --user is-active futures-bot
```

Ожидаемый ответ:

```text
inactive
```

После остановки службы ноутбук снова может переходить в сон при
закрытии крышки.

## Обновление кода

Сначала остановить бота:

```bash
systemctl --user stop futures-bot
```

Затем обновить текущую ветку:

```bash
cd /home/liudmila/futures_bot
git pull --ff-only
```

После обновления запустить и проверить:

```bash
systemctl --user start futures-bot
systemctl --user status futures-bot
```

## Если бот не отвечает

Проверить службу и последние сообщения:

```bash
systemctl --user status futures-bot
journalctl --user -u futures-bot -n 100 --no-pager
```

Затем выполнить:

```bash
systemctl --user restart futures-bot
```

Если после перезапуска бот по-прежнему не отвечает, не запускайте
вторую копию через терминал. Сначала сохраните вывод журнала для
диагностики.

## Ручные TP в Bitunix

TP можно поставить вручную в интерфейсе Bitunix. Перед этим нужно
проверить фактическую открытую позицию, направление и оставшийся
объём.

Если для позиции сохранён план бота, нельзя без проверки одновременно
оставлять ручные TP и позволять боту создавать ещё один набор. Перед
последующим запуском бота следует убедиться, что цены и объёмы ручных
TP соответствуют плану. При несовпадении бот может сообщить о
конфликте и отказаться создавать дополнительные TP.
